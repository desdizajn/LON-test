# P6.37 — Information Architecture (role + process driven)

> **Single source of truth** за sidebar реструктурирањето. Секоја промена во nav, route, placeholder — прво овде, после код.
>
> **Контекст:** LON е multi-tenant SaaS за фабрики што продаваат **stitching service** (не готов производ). Метрики: изработени парчиња, искористени минути, capacity, on-time delivery. Навигацијата е организирана по **работна позиција + процесен тек**, не по архитектурни модули.
